Personal Discord
A real-time communication application designed for messaging, channel management, and direct user interactions.

Key Features
Real-Time Messaging: Supports instant text communication across servers and direct message channels.

Server and Channel Management: Users can create custom servers, set up categorized text channels, and manage participant access.

User Authentication and Profiles: Secure user sign-up, login, and customizable user profile settings.

Interactive UI: Clean, responsive interface modeled after modern chat platform layouts for seamless user navigation.

Tech Stack and Tools
Frontend: Modern web interface framework

Backend: Real-time server communication architecture and API endpoints

Database: Persistent storage for user data, channel records, and chat history

Version Control: Git and GitHub

Getting Started
Prerequisites
Node.js (v18 or higher recommended)

Package manager (npm or yarn)

Installation and Setup
Clone the repository:
git clone https://github.com/Evis0/Personal-Discord.git
cd Personal-Discord

Install project dependencies:
npm install

Start the application:
npm start
